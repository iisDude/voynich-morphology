# Reproduction without the experimental lab

The contribution is a read-only input. `SCIENTIFIC_LAB/` is not a dependency. Scripts reject output paths inside the contribution. Create a sibling output directory and Python environment; do not run historical mutation/build scripts against this snapshot.

## Environment and exact settings

Recorded runtime: Python **3.12.14**, Windows AMD64, MSC v.1944. `environment/requirements-lock.txt` records all observed scientific distributions, including NumPy2.2.6, SciPy1.15.3, scikit-learn1.6.1, OpenCV-headless4.11.0.86, Pillow12.3.0 and Matplotlib3.10.3. Installed distribution metadata/notices and the original runtime lock are retained. Package wheels/BLAS binaries are external dependencies, not copied project code. Set `OMP_NUM_THREADS=2`, `OPENBLAS_NUM_THREADS=2`, `MKL_NUM_THREADS=2` **before importing NumPy** for the recorded matrix replay. The replay wrapper sets these defaults; override from a previous shell can change bitwise SDF results.

Common historical seed:20261005. Each trial has a separate authoritative `PLAN.json`; Direct Trial2 bootstrap uses its registered seed+2 (2,000 caption-node resamples), robustness uses20261023+2 (5,000 resamples). Pair pools, extension decisions, all selection seeds, repeated-rating mappings and solver selections are fixed and retained. `environment/SEED_INDEX.json` locates registered seed fields; the original protocols override this convenience index. No new random selection occurs during numerical replay.

## Command order

From the parent directory, after activating an external environment:

```sh
python -m pip install -r CONTRIBUTION/environment/requirements-lock.txt
python CONTRIBUTION/tests/verify_integrity.py
python CONTRIBUTION/tests/verify_package.py
python CONTRIBUTION/tests/replay_results.py --output replay_output/numerical_replay.json
```

The integrity test verifies transport hashes, decompressed original bytes and every listed entry in all12 original freezes. It separately reports204 external native sources; it does not pretend to verify newly retrieved photographs. The isolation wrapper, python CONTRIBUTION/tests/replay_isolation.py --output replay_output/isolation.json, additionally rejects original research inputs and every lab file access during the full replay. It permits installed dependency code. The numerical test recomputes both direct trials' native-mask-to32/64/128/SDF fields and ten distance matrices per trial, Trial2 AUROCs and paired caption-bootstrap intervals, robustness graph selections/all108 conditions/selection sensitivities/ordinal kappas and Feature Trial2 measurements/five matrices. It checks V5 conservation. The exact observed replay is stored at `tests/publication_checks/NUMERICAL_REPLAY.json`. Earlier annotation/class/sequence outputs are preserved and hash-verified rather than silently refitted.

`--fields-only` skips expensive distance recomputation; it is a convenience check, not a substitute for the full replay. Bitwise distance equality is strict on the recorded runtime. For another platform report any difference; do not retune metrics or change stored expected results. Wheel archive hashes were not retained, so the lock describes installed versions rather than cryptographically identical downloaded wheels.

## Original layout and source inputs

```sh
python CONTRIBUTION/scripts/materialize.py --output replay_workspace
python CONTRIBUTION/scripts/materialize.py --output replay_workspace --retrieve-native --prefix data/source/yale_native/
```

The first command restores the original `voynich-groundup/` layout from canonical payloads (roughly9GB uncompressed), leaving external native images absent. The second retrieves their exact indexed full/full IIIF URLs and rejects byte mismatches. If Yale changes JPEG serialization, retain the new source separately and report the mismatch; do not relabel its bytes with the old hash. Original private chat/PDF/archive inputs are not regenerated by this command. Historical conventional/control assays additionally require the independently obtained exact source text/UD archives identified in the provenance audit; those are unnecessary for the morphology replay.

For native re-extraction, work in a **new experiment/work copy** and use the preserved extraction functions in `scripts/frozen/build_direct_morphology2.py`, `build_direct_morphology.py` and source verification in `verify_direct_morphology2_sources.py`. After materialization/hydration, the original post-freeze source verifier can be run from `replay_workspace/voynich-groundup/src/` without replacing frozen decisions. Its scope is raster/source correspondence, not independent adjudication. Frozen build guards deliberately refuse to regenerate sealed trials in place. A researcher extending methods must fork a new directory/plan with new manifests.

## Reports, atlases and figures

`reports/` preserves original report bytes. `reports/public/` and `atlases/` are generated link-adapted views; their header identifies them as publication derivatives. `scripts/render_public_views.py` reconstructs those views **outside the snapshot**. Original render/report programs and inputs are preserved for extension; full historical render regeneration can require independently obtained source PDF/native photographs. PNG examples are canonical inputs for numerical-only inspection. Their original bytes are hash-verified, not silently replaced by rerendered images. A newly encoded PNG/NPZ need not have the original file hash even when its decoded array is equal.

`manifests/CONTRIBUTION_FREEZE.json` seals the completed package; `SNAPSHOT.sha256` provides its digest. `manifests/original/` contains unchanged earlier freeze bytes and `FILE_INDEX.json` preserves their original hashes. Publication tests are additional checks and do not rewrite an old manifest to match the new folder structure.
