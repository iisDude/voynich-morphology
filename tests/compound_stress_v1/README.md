# Declared compound-encoding sensitivity

Run `run.py` from the Voynich Project. This is a post-freeze comparison test of the ledger's conservative EVA compounds (including iin/in), with an additional ee collapse. Longest match is explicit; encoded lengths are recomputed, original ordinal positions preserved. Frequencies, controls, caption bootstraps and nulls are fixed in `config.json`. The comparison does not define or validate physical writing units.
